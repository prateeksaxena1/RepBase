# RepBase 🏋️

A free, unlimited gym workout logger for iOS and Android.

> Built as a direct alternative to Hevy — which limits free users 
> to only 4 workout routines. RepBase gives you unlimited routines, forever.

## Features

- **Unlimited Routines** — create as many workout plans as you need
- **Workout Logging** — log sets, reps, and weight for every exercise
- **Progress Charts** — track your max weight over time per exercise
- **Workout History** — view all past sessions
- **Pre-filled Exercise Library** — Push, Pull, Legs, Full Body
- **Custom Exercises** — add your own exercises
- **100% Local** — no account needed, all data stored on device

## Tech Stack

- React Native + Expo
- Expo Router (file-based navigation)
- expo-sqlite (local database)
- Zustand (state management)
- react-native-gifted-charts (progress charts)

## Getting Started
```bash
git clone https://github.com/prateeksaxena1/RepBase.git
cd RepBase
npm install
npx expo start
```

Scan the QR code with Expo Go on your phone.
